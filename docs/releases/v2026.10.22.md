# Bankai v2026.10.22

This Linux release brings a faster Rust interface, a searchable character picker,
expanded artwork, and safer backup and restore in both desktop editions.

## Highlights

- Background wallpaper, portrait and backup loading keeps the Rust interface
  responsive. Portrait caching and batched character metadata reduce repeated work.
- Search terminal characters with thumbnails, faction/form filters, favorites,
  recent selections, keyboard navigation and an always-available Random choice.
- Eighteen desktop presets and 46 terminal portraits with color/manga editions,
  including expanded TYBW artwork, appearance controls and saved custom presets.
- Review snapshot contents before restoring. Both editions use transactional
  restore, a shared path policy and coordinated locking, with stricter validation
  of manifests, file types and saved preferences.
- Improved keyboard focus, accessible descriptions, result announcements and
  layouts for smaller displays.
- Optional manga SDDM login scenes follow the desktop or a configured shuffle pool.
  Activation remains a separate administrator operation.

## Downloads

- `bankai-python.tar.gz`: Python edition with shared artwork and terminal theme.
- `bankai-rust-source.tar.gz`: Rust edition source with shared artwork and theme.
- `bankai-rust-linux-x86-64.tar.gz`: Rust binary built by the release workflow on
  Ubuntu 24.04. Requires compatible Qt and system runtime libraries.
- Each download has a SHA-256 sidecar. Follow the edition's included install guide
  for prerequisites, preview, upgrade and removal.

The Windows WinUI edition is under development and is not included in this release.

## Verification and limits

The previous Linux validation passed 60 repository Python tests, 26 Python
snapshot checks, 23 Python offscreen UI checks (one sandbox socket skip), 43 Rust
tests, 22 compiled-binary integration checks, Clippy and native offscreen smoke
checks. The user confirmed live KDE wallpaper/color application and single-window
activation. Release CI reruns its checks before attaching downloads.

Live KDE tray behavior, spoken screen-reader announcements, SDDM authentication
and boot behavior still need desktop verification. Offscreen tests do not verify
those behaviors. Local CachyOS binary packages require matching runtime libraries;
they are separate from the Ubuntu-built release binary.
