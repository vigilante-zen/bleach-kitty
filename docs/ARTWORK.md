# Artwork and provenance

[Browse the color and manga gallery](GALLERY.md)

The payload contains 40 color portraits and 40 matching manga portraits: 32 characters including alternate forms. All are unofficial AI-generated Bleach fan art. The manga editions use black-and-white ink, screentones and restrained character accents. No official manga pages or anime screenshots are included as artwork assets.

Artwork was produced during development using the built-in imagegen tool. The manga prompt records and the two roster expansions are retained under [prompts](prompts/). They document prompts, references and output hashes where recorded. Initial color-generation prompts and the first Urahara manga prompt were not fully preserved in the available records; the repository does not invent provenance for those earlier assets. Local reference paths in these historical records have been normalized to `~/`; they describe the development setup, not installer destinations. Output files are now under `files/.config/fastfetch/portraits/` and `files/.config/fastfetch/manga/`.
